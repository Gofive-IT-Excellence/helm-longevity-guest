# HELM Longevity — Guest preview

เว็บรุ่นใหม่สำหรับ GitHub Pages แยกจากเวอร์ชันทดสอบมือถือเดิม แสดงหน้าต้อนรับพร้อมปุ่มเข้าสู่ระบบ โดยยังไม่ตรวจสอบบัญชีหรือรหัสผ่าน

## ขอบเขต Production sprint ปัจจุบัน

หน้าเว็บแสดงเฉพาะ **สแกนรูปอาหารเพื่อดูแคลอรีโดยประมาณ** และ **วงล้อสุ่มเมนู** ฟีเจอร์อาหารสะสม น้ำ ก้าว กิจกรรม โปรไฟล์ และ AI เทรนเนอร์ยังอยู่ในไฟล์ต้นฉบับ แต่ถูกซ่อนจากเมนูและหน้าแรกใน sprint นี้ การเปิดกลับทำได้โดยถอด `sprint-focus.js` และ `sprint-focus.css` ออกจากขั้นตอน build

ข้อมูลอาหาร น้ำ และกิจกรรมเก็บในเบราว์เซอร์ของเครื่องนั้น ข้อมูลไม่ซิงก์ข้ามเครื่อง และรูปอาหารไม่ถูกเก็บหลังปิดหน้า

การวิเคราะห์รูปด้วย HELM เรียกผ่าน n8n โดยไม่ใส่ HELM API key ในโค้ดสาธารณะ `config.js` เปิดการวิเคราะห์เฉพาะ `helmlongevity.go5.online` ซึ่งตรงกับ Origin ที่ workflow อนุญาต ส่วน GitHub Pages ยังเป็นพรีวิวที่ไม่เรียก AI ผลจากภาพเป็นค่าประมาณและต้องตรวจชื่ออาหารกับปริมาณก่อนใช้

## จัดการเมนูวงล้อ

เปิด `admin.html` เพื่อแก้ชื่ออาหารและไอคอนของวงล้อ 6 ช่อง แล้วกด **เผยแพร่เมนูขึ้นเว็บ** หน้านี้เรียก GitHub Contents API เพื่อ commit เฉพาะ `menus.json` ไปที่ `main` ด้วย Fine-grained personal access token ที่ผู้เผยแพร่วางในช่องขณะใช้งาน กำหนด token ให้เข้าถึงเฉพาะ repository `helm-longevity-guest` ด้วยสิทธิ์ Contents: Read and write และกำหนดวันหมดอายุสั้น ๆ Token ไม่ถูกบันทึกใน localStorage หรือไฟล์เว็บ และถูกล้างหลังเผยแพร่สำเร็จ หน้าเว็บทั่วไปไม่ต้องใช้ token

เว็บบริษัทดึง `menus.json` จาก GitHub Pages โดยตรง (GitHub Pages อนุญาต CORS) หลัง commit แล้วรอ GitHub Pages เผยแพร่และรีเฟรชหน้าเว็บได้เลย ไม่ต้อง Deploy Coolify ซ้ำสำหรับการเปลี่ยนเมนู โปรดรอให้ GitHub Pages และแคชอัปเดต ซึ่งอาจใช้เวลาหลายนาที

## พัฒนาในเครื่อง

```sh
python3 build_frontend.py
python3 -m http.server 8102
```

เปิด http://127.0.0.1:8102/ เพื่อดูหน้าเว็บ
