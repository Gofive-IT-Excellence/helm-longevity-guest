รายการอาหาร

เรียงตามตำแหน่งบนวงล้อ ช่องที่ 1 เริ่มด้านขวาบน • กรุณาใส่ชื่อทุกช่อง

เผยแพร่เมนู

ใช้ GitHub token ของบัญชีที่มีสิทธิ์แก้ repository นี้ โดยกำหนดสิทธิ์ Contents: Read and write เฉพาะ repository นี้และกำหนดวันหมดอายุ Token ใช้เฉพาะตอนกดเผยแพร่ ไม่บันทึกในเครื่องหรือไฟล์เว็บ

ตั้งค่าครั้งแรก

  1. สร้าง Fine-grained personal access token บน GitHub เลือกเจ้าของ repository และเลือกเฉพาะ helm-longevity-guest
  2. ตั้งค่า Contents: Read and write และกำหนดวันหมดอายุสั้น ๆ จากนั้นวาง token ในช่องด้านบน
  3. แก้เมนูแล้วกด เผยแพร่เมนูขึ้นเว็บ ระบบจะบันทึกไฟล์ menus.json บน GitHub

หน้าเว็บทั่วไปไม่ต้องใช้ token เมนูจะเปลี่ยนสำหรับทุกคนหลัง Coolify Deploy commit ใหม่ การแก้ในฟอร์มก่อนกดเผยแพร่ยังไม่เปลี่ยนเมนูของผู้อื่น
