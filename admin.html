จัดการเมนูวงล้อ

แก้ชื่ออาหารและไอคอนของทั้ง 6 ช่อง แล้วนำรายการไปเผยแพร่ผ่าน GitHub เพื่อให้ทุกคนเห็นเมนูใหม่

รายการอาหาร

เรียงตามตำแหน่งบนวงล้อ ช่องที่ 1 เริ่มด้านขวาบน • กรุณาใส่ชื่อทุกช่อง

วิธีเผยแพร่ให้ทุกคนเห็น

  1. แก้เมนูด้านบน แล้วกด คัดลอกข้อมูลเมนู
  2. เปิดไฟล์ menus.json บน GitHub ด้วยบัญชีที่มีสิทธิ์แก้ไข repository
  3. แทนที่เนื้อหาเดิมด้วยข้อมูลที่คัดลอก แล้วกด Commit changes รอ GitHub Pages เผยแพร่ จากนั้นรีเฟรชหน้าเว็บ

หน้านี้ไม่เก็บรหัสผ่านหรือสิทธิ์แอดมิน การแก้ในฟอร์มยังไม่เปลี่ยนเมนูของผู้อื่นจนกว่าจะ Commit บน GitHub ซึ่งตรวจสิทธิ์ของบัญชีผู้เผยแพร่
